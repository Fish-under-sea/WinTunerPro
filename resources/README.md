# resources —— 离线资源

保证工具在无网络环境下也能完整运行的本地资源包。

## 子目录

- `drivers/`：离线驱动安装包（如驱动总裁离线命令行版本）。
- `runtimes/`：运行库离线包（VC++ 全家桶、.NET Framework、DirectX）。
- `themes/`：美化风格包（赛博风 / 简约风 / 电竞风等，含壁纸、图标配置）。
- `fonts/`：中文字体安装包（更纱黑体、霞鹜文楷等）。

## 重要约定

- 本目录下的实际资源文件**通常体积大且可能涉及版权**，默认**不纳入 Git**（见根目录 `.gitignore`），仅保留目录结构与清单说明。
- 实际分发通过外部渠道或 Git LFS，仓库内只放占位说明与资源清单。
- LTSC 系统镜像由用户自备，不随工具分发。
