# 开发路线

> 本文档描述 WinTuner Pro 的阶段性开发计划。周期为预估排期，会随实际进度调整。

## 阶段规划

| 阶段 | 周期 | 目标 |
| --- | --- | --- |
| P0 | 第 1-2 周 | 基础架构：Electron 壳 + 硬件检测 + PowerShell 链路打通 |
| P1 | 第 3-4 周 | 系统优化（服务/电源/网络）+ N 卡调优 |
| P2 | 第 5-6 周 | OEM 调度（联想/华硕先行）+ A 卡调优 |
| P3 | 第 7-8 周 | 系统重装 + 初始化 + 重启续执行 |
| P4 | 第 9-10 周 | 美化模块 + 风格包 + 备份迁移 |
| Beta | 第 11-12 周 | 内测 + Bug 修复 + 性能调优 |
